## 📊 DATABASE SCHEMA

### users table
- id, username, email, password (hashed)
- role (student/admin), grade
- created_at timestamp

### game_sessions table
- id, user_id, subject, game_type
- score, time_spent, completed
- created_at timestamp

### progress table
- id, user_id, subject, concept
- mastery_level, attempts, best_score
- updated_at timestamp

## 🔧 API ENDPOINTS

### Public
POST /api/register          # Student registration
POST /api/login             # Authentication
GET  /                      # Landing page
GET  /game                  # Games interface
GET  /admin                 # Admin dashboard
GET  /health                # Health check

### Protected (Requires JWT)
POST /api/game-session      # Save game results
GET  /api/progress/:userId  # Get student progress

### Admin Only
GET  /api/admin/dashboard   # Analytics data
GET  /api/admin/users       # All students
GET  /api/admin/sessions    # All game sessions
